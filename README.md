# E-commerce Project

Nesse projeto pratico da Rocketseat foi possivel criar uma API que simula um sistema de e-commerce com **Python** e **Flask**, onde o foco principal foi a criação das rotas para as funcionalidades, integrar um banco de dados e autenticação de usuario.

## Funcionalidades

- Rotas para navegação e visualização de produtos.
- Rota para adicionar produtos ao carrinho de compras.
- Rota para realizar o checkout.
- Rota para gerenciar o estoque de produtos.

## Tecnologias Utilizadas

- **Linguagem**: Python
- **Framework**: Flask
- **Database**: SQLite

## Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/ricardojaj/E-commerce-com-Python-e-Flask.git
   ```

2. Crie e ative o ambiente virtual:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   ```

3. Instale as dependências:

   ```bash
   pip install -r requirements.txt
   ```

4. Execute a aplicação:
   ```bash
   flask run
   ```
